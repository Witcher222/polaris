# Polar Nexus

Build a complete, highly polished, responsive web application called POLARIS — Polar Science Knowledge & Outreach, based on this concept:

Integrated Polar Science Outreach, Knowledge Repository & Media Dissemination Portal

Do NOT make this a basic institutional website. Build a large, visually immersive, multi-page digital ecosystem combining a scientific archive, Instagram-like discovery feed, expedition journal, interactive polar map, research repository and outreach platform.

DESIGN / VISUAL IDENTITY

Create a premium polar exploration + scientific technology aesthetic.

Mostly LIGHT UI inspired by:
snow, ice, glaciers, polar oceans, research stations and aurora.

Palette:

Background: #F7FAFC, #FFFFFF, #EEF7FA

Ice: #DDF3F8, #B9E6F0

Polar blue: #073B4C, #0B5369

Teal: #52C7C0

Aurora accent: #9B8AFB

Use spacious layouts, elegant typography, rounded cards, subtle shadows, thin icy borders, glassmorphism, soft gradients, scientific grid patterns and premium imagery.

Add an optional Polar Night dark mode using deep navy + cyan + subtle aurora.

Use Framer Motion for smooth animations:
page transitions, scroll reveals, staggered cards, hover effects, animated counters, map markers, timelines, modals, image zoom, subtle snowfall and very subtle aurora effects.

Keep animations elegant and performant.

Build the entire multi-page application, not just the homepage.

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
